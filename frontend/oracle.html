The Rugpull Oracle

When NOMOS sees a token added to a NostalgiaForInfinity blacklist, it issues a signed rug-risk claim: the reasoning is hashed, pinned to IPFS, and anchored on Arc — provenance from the GitHub commit all the way to the on-chain attestation. Bonds stake for or against the prediction; the losing side is slashed on resolution.

  1. NFI SignalA token is added to a blacklist-<exchange>.json commit.
  2. Claim + HashNOMOS builds the reasoning trace; sha256 of canonical JSON.
  3. IPFSThe full trace body is pinned and addressed by CID.
  4. Arc AnchortraceHash + claim committed to TraceRegistry + ClaimRegistry.
  5. ResolveDid it drop past the threshold in the window? Bonds settle.
